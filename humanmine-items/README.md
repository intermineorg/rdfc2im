# humanmine-items

The stock `intermine-items-xml-file` source registered under its own type name, so that the
integration keys and model additions that rdfc2im generates can travel with it. **No Java.**

```
humanmine-items.properties                     have.file.xml.tgt = true  (identical to intermine-items-xml-file)
src/main/resources/humanmine-items_keys.properties   generated by `rdfc2im project` (make fork-sync copies it here)
src/main/resources/humanmine-items_additions.xml     generated by `rdfc2im project`
```

Install: copy this directory into `humanmine-bio-sources/`, add `include 'humanmine-items'` to
`settings.gradle`, `./gradlew :humanmine-items:install`. Then use `out/_mine/project.xml`, and put
each `out/<source>/items/<source>.xml` where its `src.data.file` points.

If a source's items file is large, `intermine-items-large-xml-file` (`have.large.file.xml.tgt = true`)
is the same loader streaming through a target items database; switch the properties line if needed.
